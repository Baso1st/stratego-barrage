# CLAUDE.md

Instructions for Claude Code when working in this repository.

## Project

A web-based, single-player version of Stratego Barrage where you play against the computer. It is front end only (no back end) and built with React. See `README.md` for the game overview.

## Rules

- **Never run `git add` or `git commit`.** The user stages and commits all changes manually. Leave changes in the working tree for them to review.

## Roadmap

`docs/ROADMAP.md` tracks the current status, roadmap, decisions, and open questions. It is imported below so it loads at the start of every session.

- Keep it up to date: tick off roadmap items as they're finished, record decisions as they're made, and update "Current status" at the end of a piece of work.
- Before starting new work, check it to see where things stand.

@docs/ROADMAP.md

## Feature plans

`PLAN.md` is reserved for per-feature plans. The user asks for one at the start of a feature and deletes it when the feature is done. Don't use that name for anything else.
